| Question | Short answer |
|---|---|
| Does FL beat a node training alone? | **Yes for small data and new cameras. No for a mature site using the shared model as-is.** Federated + a short local fine-tune has the best balanced accuracy at every data size (0.771 at 50 events per site, 0.879 at 5,000). Local-only catches up by 1,500 events. |
| What does a brand-new camera get? | The fleet model works on day one: **0.75 balanced accuracy and 0.72 anomaly recall with zero local events**, against 0.10 untrained. Local-only needs about 150 events to match the accuracy and about 500 to match the anomaly recall. |
| Does detection keep running during training? | **Yes on every Hailo build tested:** pi5-hailo, the pipelined build and pi5-hailo-fine all stayed above 12 FPS during a real Flower round. It **does not hold 12 FPS** if the threat model runs on the CPU (10.3 FPS). Single-run PC measurements, not Pi measurements. |
| Can one bad camera poison the fleet? | **Yes with today's FedAvg server.** One crashed node destroys the model (0.00), and a boosted hostile node cuts anomaly recall from 0.64 to 0.08. robust.py blocks the crash, noise, sign-flip and heavily boosted attacks with no false rejections, but **a moderately boosted (x2.5) or quiet label flip gets through it.** Plain trimmed mean handled both boosted label flips better. |
